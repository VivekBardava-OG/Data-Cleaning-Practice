## 📌 Overview
This repository is dedicated to practicing essential data preprocessing and cleaning techniques. The goal of this project is to take a "messy" real-world dataset—the **Kaggle Airbnb Dataset**—and transform it into a clean, analysis-ready format.

Data cleaning is a critical step in any data science pipeline, as the quality of the insights depends entirely on the quality of the data.

## 📊 The Dataset
- **Source:** Kaggle Airbnb Open Data
- **Description:** The dataset contains information about Airbnb listings, including pricing, location, room types, and review scores.
- **Challenges:** The raw data contains missing values, inconsistent formatting, outliers in pricing, and duplicate entries.

## 🛠️ Tech Stack
- **Language:** Python 3.11+
- **Environment Management:** [uv](https://github.com/astral-sh/uv) (Fast Python package installer and resolver)
- **IDE:** VS Code
- **Libraries:**
  - `pandas`: For data manipulation and cleaning.
  - `numpy`: For numerical operations.
  - `matplotlib` / `seaborn`: For visualizing missing data and outliers.
